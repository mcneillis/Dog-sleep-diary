# Soft Meadow — dog sleep diary wireframes

Clickable HTML drawings for Sara’s senior-dog owner diary. **App Ltd · Settle.** Soft Meadow is the look of this draft. This is **not** a live product, **not** an app-store listing, and **not** a medical device.

Analytics: **OFF**. Store listing: **held** (do not store). No CQC badge. Nothing here diagnoses a dog or sends a pack to a vet.

These pages were rebuilt from the 6 September 2026 Soft Meadow screens (Home, Night, Hand-in, Start, Create account, Privacy). No HTML box pack was attached.

## How to open (no coding)

1. Download this folder.
2. Double-click `index.html`.
3. Tap through Start → Create account → Privacy → Home / Night / Hand-in.

Or, with a simple local server:

```bash
python3 -m http.server 43217
```

Then open http://127.0.0.1:43217/
